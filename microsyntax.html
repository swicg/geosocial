Geographical Microsyntax

This document identifies several geographical notation formats that may be appropriate as microsyntax for geosocial applications. It lists and describes each such format. It also provides guidance on how to apply microsyntax to ActivityPub content and objects.

This is an experimental specification and is undergoing regular revisions.

Geographical microsyntax options

Open Location Codes

Plus Codes, also called Open Location Codes, are a format for encoding lat/lon pairs efficiently. The algorithm was developed by Google and released under the Apache license.

Documentation Plus Codes
Pattern(s)
  • 10 or more letters and numbers joined by a "+"
  • 6 or more letters and numbers joined by a "+", followed by a comma-separated location identifier
Examples
  • 87C4VXQ7+QV
  • GV3C+8X, London, United Kingdom
Web page URI template https://plus.codes/{pluscode}
ActivityPub object URI template (none)

what3words

what3words is a proprietary notation provided by what3words Limited.

Documentation what3words API
Pattern(s) "///" + word + "." + word + "." + word (words are lowercase ascii letters only)
Examples
  • ///brick.camp.colleague
  • ///warns.booed.snoring
Web page URI template https://what3words.com/{threewords}
ActivityPub object URI template (none)

Mapcode

Mapcode is a patented notation provided by the Mapcode Foundation, a Netherlands non-profit. They are free for non-commercial use.

Documentation About Mapcodes
Pattern(s)
  • (letters and numbers) "." (letters and numbers)
  • (country name) " " (letters and numbers) "." (letters and numbers)
  • (3-letter ISO 3166-1 code) " " (letters and numbers) "." (letters and numbers)
  • (Unprefixed ISO 3166-2 code) " " (letters and numbers) "." (letters and numbers)
  • (Prefixed ISO 3166-2 code) " " (letters and numbers) "." (letters and numbers)
Examples
  • 49.4V
  • Netherlands 49.4V
  • NLD 49.4V
  • DC 18.JQZ
  • US-DC 18.JQZ
Web page URI template https://plus.codes/{threewords}
ActivityPub object URI template (none)

L: prefix

This notation identifies a location with natural language. It was proposed as part of the Microsyntax.org effort.

Documentation N/A
Pattern(s)
  • "L:" + (natural language location description)
Examples
  • L:San Francisco
  • L:London, UK
Web page URI template (none)
ActivityPub object URI template (none)

Applying microsyntax to ActivityPub objects

This section describes ways that ActivityPub applications can apply geographical microsyntax.

Linking

Clients or servers can convert patterns that match geographic microsyntax into a link to the Web page for that location.

This conversion can be done on the sending end, from the server or client that creates the text. Alternately, it can be done on the receiving end.

Consider the following input microsyntax.

        I am at 87Q8GC37+86

It could be converted to the following HTML:

        I am at <a href="https://plus.codes/87Q8GC37+86">87Q8GC37+86</a>
